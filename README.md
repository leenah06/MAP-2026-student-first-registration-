# MAP-2026-student-first-registration-
This repo will hold the code used in my MAP (mentored advanced project) about 'student first registration via integer programming'

All the files here should be placed in the same folder. Then open realRegistrationModel1.0.1.m file to run the script. Now, we have realRegistrationModelFA25 and realRegistrationModelSP26.

Note: The FinalScript.m isnt tested, because we're having difficulty getting an initial solution. SO when running, we might get an error. Anyways, to run it, just run the file 'FinalScript.m', make sure all the files are in the same folder. The realRegistrationModel.m file is not needed (or any of its versions) to fun FinalScript.m.

Information about ModelWithSection.m : It also returns newT, newS, newR, and a randomly-created newF. This code is tested, and correct. To run it, you need the files funcs.m and ModelWithSections.m in the same folder, and just run ModelWithSections.m. You might want to remove any semicolons at the end of the new matrices if there are any.
